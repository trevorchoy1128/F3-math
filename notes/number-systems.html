學習目標Learning objectives

  • 理解位值的意義：同一個數字放在不同位置，代表不同的值。
  • 認識十進制（逢十進一）及二進制（逢二進一）的位值。
  • 把十進制數及二進制數寫成展開式。
  • 把二進制數轉換為十進制數。
  • Understand the meaning of place value: the same digit in different positions represents different values.
  • Recognise the place values of the decimal system (carry over at ten) and the binary system (carry over at two).
  • Write decimal and binary numbers in expanded form.
  • Convert binary numbers into decimal numbers.

概念講解Key concepts

1. 甚麼是位值？1. What is place value?

請看 555 這個數。三個數字都是 5，但它們代表的值並不相同：

Look at the number 555. All three digits are 5, but they do not represent the same value:

5百位 → 500hundreds → 500
5十位 → 50tens → 50
5個位 → 5ones → 5

一個數字代表的值，取決於它所在的位置。每個位置的「份量」，稱為位值（place value）。

The value a digit represents depends on its position. The "weight" of each position is called its place value.

2. 位值有甚麼作用？2. Why is place value useful?

  • 用少量數字寫出任何數：十進制只有 0 至 9 十個數字，但靠位值，就能寫出無論多大的數。
  • 「0」可以佔位：35 和 305 的分別，在於中間的 0 把 3 推到了百位。
  • 計算的基礎：直式加減中的「進位」和「借位」，都是建基於位值。
  • Write any number with only a few digits: the decimal system has only the ten digits 0 to 9, but with place value we can write a number of any size.
  • "0" can act as a placeholder: the difference between 35 and 305 is that the 0 in the middle pushes the 3 into the hundreds place.
  • The basis of calculation: "carrying" and "borrowing" in column addition and subtraction are both based on place value.

3. 十進制：逢十進一3. Decimal: carry over at ten

日常使用的是十進制（decimal）。它用 0 至 9 共十個數字；某個位數滿 10，便向左進一位。因此，每向左移一位，位值便乘以 10。

In daily life we use the decimal system. It uses the ten digits 0 to 9; when a place reaches 10, we carry 1 to the place on its left. Therefore, each time we move one place to the left, the place value is multiplied by 10.

For example: 3025 = 3 × 1000 + 0 × 100 + 2 × 10 + 5 × 1. Writing a number this way is called its expanded form.

4. 二進制：逢二進一4. Binary: carry over at two

二進制（binary）只用 0 和 1 兩個數字；某個位數滿 2，便向左進一位。因此，每向左移一位，位值便乘以 2。

The binary system uses only the two digits 0 and 1; when a place reaches 2, we carry 1 to the place on its left. Therefore, each time we move one place to the left, the place value is multiplied by 2.

電腦內部使用二進制，因為電路只有「通電」（1）和「斷電」（0）兩種狀態。

Computers use binary internally because a circuit has only two states: "on" (1) and "off" (0).

6. 記法6. Notation

怎樣分辨是哪一種進制？ 二進制數會在右下方寫上細小的 2，例如 10112，讀作「二進制數一零一一」。 沒有標示的數（例如 1011）一般當作十進制數，即「一千零一十一」。
How can we tell which number system is being used? A binary number has a small 2 written at its lower right, e.g. 10112, read as "binary one-zero-one-one". A number without this mark (e.g. 1011) is normally taken as a decimal number, i.e. "one thousand and eleven".

7. 把二進制數轉換為十進制數7. Converting binary numbers into decimal numbers

  1. 由右至左寫出每個數字的位值：1、2、4、8、16……
  2. 把每個數字乘以它的位值（即寫成展開式）。
  3. 把所有結果相加。
  1. From right to left, write down the place value of each digit: 1, 2, 4, 8, 16, …
  2. Multiply each digit by its place value (i.e. write the number in expanded form).
  3. Add all the results together.

例如：10112 = 1 × 8 + 0 × 4 + 1 × 2 + 1 × 1 = 8 + 0 + 2 + 1 = 11

For example: 10112 = 1 × 8 + 0 × 4 + 1 × 2 + 1 × 1 = 8 + 0 + 2 + 1 = 11

小技巧 0 乘以任何位值都是 0，所以只需把「1」所在位置的位值加起來：10112 → 8 + 2 + 1 = 11。
Tip 0 multiplied by any place value is 0, so we only need to add up the place values of the positions holding a "1": 10112 → 8 + 2 + 1 = 11.
常見錯誤
  • 把 10112 讀成「一千零一十一」。
  • 由左邊開始數位值。位值應由最右邊的 1 開始。
  • 以為最右邊的位值是 2。其實最右邊的位值是 1。
  • 在二進制數中寫出 2 或以上的數字。二進制只有 0 和 1。
Common mistakes
  • Reading 10112 as "one thousand and eleven".
  • Counting place values from the left. Place values should start with 1 at the rightmost place.
  • Thinking that the rightmost place value is 2. In fact, the rightmost place value is 1.
  • Writing a digit of 2 or above in a binary number. Binary uses only 0 and 1.

教學建議Teaching suggestions

課堂頁面各工具的用法Using the tools on the class page

  • ① 點數咭：先讓學生數每張咭的點數，發現「每張是右邊一張的 2 倍」。翻開一張咭時，強調「這個 1 代表 8 粒點」，而不只是「1 在第四位」。下方同時顯示數量、寫法、讀法，可請學生把三者對應起來。「挑戰」適合全班遊戲。
  • ② 位值表：輸入二進制數，顯示每個數字乘以位值，再寫成展開式。可故意輸入「1021」，讓學生解釋為何二進制不能有 2。
  • ③ 逢十進一 vs 逢二進一：在按「+1」之前，先請學生預測哪一步會進位、進位幾次（例如 7 → 8、15 → 16），再按鍵驗證。
  • ④ 糖果包裝工廠（延伸）：用「每 2 個包成 1 個大包裝」說明逢二進一。包裝完成後，每種包裝最多只有 1 個，由左至右寫下就是二進制數。
  • ① Dot cards: First let students count the dots on each card and discover that "each card has twice as many dots as the card on its right". When turning a card over, stress that "this 1 stands for 8 dots", not just "the 1 is in the fourth place". The quantity, written form and spoken form are shown together below, so students can be asked to match the three. The "Challenge" works well as a whole-class game.
  • ② Place value table: Enter a binary number to show each digit multiplied by its place value, then written in expanded form. You may deliberately enter "1021" and ask students to explain why binary cannot contain a 2.
  • ③ Carry at ten vs carry at two: Before pressing "+1", ask students to predict which step will cause a carry and how many carries there will be (e.g. 7 → 8, 15 → 16), then press the button to check.
  • ④ Candy packing factory (extension): Use "pack every 2 into 1 bigger pack" to illustrate carrying over at two. When packing is finished, there is at most 1 of each type of pack; writing them down from left to right gives the binary number.

研究的啟示What the research says

  • 位值的四個性質（Ross, 1989）：位置性、底數性、乘法性（數字 × 位值）、加法性（各部分相加）。展開式正好同時體現乘法性及加法性。
  • 重視「數量值」（Thompson, 2003）：學生能說出「1 在 8 的位」，不代表明白它代表 8 件東西。可配合實物或點數卡（CS Unplugged 二進制卡）。
  • 變易理論（Marton；盧敏玲）：固定一樣、改變另一樣，學生才會注意到關鍵特徵。例如數字不變（101），只改變進制；或數值不變，只改變寫法。
  • 數量、寫法、讀法互相連繫（Fuson 等, 1997）：學生要把實際數量、書寫的數字及讀法三者連起來，理解才會穩固。
  • 包裝情境（McClain, 2003）：以包裝糖果的情境（粒 → 袋 → 盒）解釋分組及進位，令「逢二進一」有具體意思。
  • Four properties of place value (Ross, 1989): positional, base, multiplicative (digit × place value) and additive (the parts are added together). Expanded form shows both the multiplicative and the additive properties at the same time.
  • Emphasise "quantity value" (Thompson, 2003): a student who can say "the 1 is in the 8s place" does not necessarily understand that it stands for 8 objects. Support this with concrete objects or dot cards (CS Unplugged binary cards).
  • Variation theory (Marton; Lo Mun Ling): students notice critical features only when one thing is kept the same while another is changed. For example, keep the digits the same (101) and change only the number system; or keep the value the same and change only the way it is written.
  • Linking quantity, written form and spoken form (Fuson et al., 1997): understanding becomes secure only when students connect the actual quantity, the written numeral and the way it is read.
  • Packing context (McClain, 2003): a candy-packing context (pieces → bags → boxes) explains grouping and carrying, giving "carry over at two" a concrete meaning.
